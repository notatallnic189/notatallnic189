## Current project

**[whyred-nethunter-kernel](https://github.com/notatallnic189/whyred-nethunter-kernel)**: turns a Redmi Note 5 Pro (whyred) running LineageOS 18.1 into a Kali NetHunter platform.

- HID gadget for keystroke injection (DuckHunter style)
- external RTL8812AU support: monitor mode and packet injection over OTG
- signed driver module, flashable AnyKernel3 zip
- every build automated on GitHub Actions, downloads free

Grab [v1.0.0](https://github.com/notatallnic189/whyred-nethunter-kernel/releases/tag/v1.0.0) if your whyred needs a second life.
